# Procly · Releases

Instaladores e atualizações da **app desktop do Procly** (levantamento de processos com inteligência artificial).

## Descarregar
Na página **[Releases](https://github.com/jaimeaugusto11/prockly-releases/releases/latest)**, descarregue o instalador para Windows (`Procly_x.y.z_x64-setup.exe`).

A app precisa de uma **licença de utilizador**: depois de entrar com a sua conta, cole a chave em **Definições → Licença**. Cada licença pode ser ativada em até 2 computadores.

## O que está aqui
| Caminho | Conteúdo |
|---|---|
| Releases | Instaladores da app desktop, um por versão. |
| `licencas/estado.json` | Lista **assinada** das licenças revogadas (só números, sem dados pessoais). Publicada automaticamente pelo registo de licenças; o servidor do Procly verifica a assinatura antes de a usar. |

O código-fonte do Procly não está neste repositório.
